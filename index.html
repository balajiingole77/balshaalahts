🪔 Sunday School Tracker

Attendance, lesson notes, and parent updates
Pilot proposal
Built by a Balshala teacher to try for one class over a few weeks. Replaces paper attendance with a tap-to-mark roster, and generates a ready-to-paste weekly update for the class WhatsApp group. No new accounts or apps for parents, nothing changes for them except getting a clearer weekly note. If it's useful, happy to expand it. If not, no harm done, it's a link, not a system.
